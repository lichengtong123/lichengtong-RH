# Mathematica 程序（书中曲面图与零迹线图）

本目录是书中第 5、7、9、10、13、17 章三维曲面图与零迹线图的 Mathematica 程序。所需环境见 [运行环境建立与程序安装说明](../docs/运行环境建立与程序安装说明.md)。

## 在线观察

在线版将通过 Wolfram Cloud 在浏览器中显示图形，不需要在读者本机安装 Mathematica 或 Wolfram Player。下表的“在线观察”一栏用于提供各图经过实际发布和检查的公开链接。

**当前状态：在线版尚未发布。** 标为“待发布”的项目目前没有可用的在线观察链接；现阶段请下载对应 `.nb`，使用本机 Wolfram Player 查看已保存的图形。GitHub 上的 `.nb` 文件链接是下载入口，不是网页播放器。

在线版与下载版分别维护。云端发布后，将检查未登录读者能否访问，以及三维图的旋转、缩放是否正常，再启用相应链接。在线交互受 Wolfram Cloud 的功能、账号方案及资源额度约束，不承诺任意参数修改或重新计算；已保存图形的在线发布方式见 [Wolfram 官方说明](https://reference.wolfram.com/language/workflow/PublishANotebookToTheCloud.html)。

## 文件概况

本目录以当前书稿的 Mathematica 源程序为准，共有 **17 个绘图脚本和 1 个共用样式文件**，均附同名 `.nb` 副本。绘图笔记本保存了已求值的图形输出，不只是将源码换一个扩展名。图 10.1 的笔记本含实部、虚部两幅图，因此 17 个绘图笔记本共保存 18 幅图形。

**两种用途：**`.wl` 文件供已安装 Mathematica 的读者修改参数、求值计算并重新生成图形；`.nb` 文件供读者使用免费的 [Wolfram Player](https://www.wolfram.com/player/) 打开，显示、观察已保存的图形，不必自行运行绘图程序。Player 不替代 Mathematica 的编辑与重新计算功能。

本目录共 18 组同名文件（36 个文件）。8 份旧版笔记本已从当前版本移除，请使用下表中与图号对应的新文件；旧文件仍可通过 Git 历史查阅。

## 使用免费的 Wolfram Player 观察

下载相应 `.nb` 文件后，用 Wolfram Player 打开，直接查看“已求值图形”部分；同一文件中的源码组默认折叠，观察图形不需要执行它，也不需要安装配套 `.wl` 文件。修改后的图形需要由 Mathematica 重新求值并保存输出，Player 不会自动运行外部源码或重新计算整幅曲面。

这里承诺的是查看已保存的图形，不将普通 `.nb` 等同于可运行任意动态控件的应用。旋转、缩放及动态控件的可用范围，应以实际 Player 版本与许可为准；涉及内核求值的交互不能仅凭文件扩展名保证可用。官方对普通 `.nb` 与可交互部署格式的区别见 [Wolfram Player FAQ](https://www.wolfram.com/player-pro/faq/)。

## 在 Mathematica 中修改参数与重新计算

[书图样式.wl](书图样式.wl) 不单独生成插图，负责共用视点、字号、中文字体、颜色、线宽、图例、零点标记及 PDF 导出函数；[同名 .nb](书图样式.nb) 仅保存样式源码供查阅，不含独立图形。多数绘图脚本通过 `Get` 载入它，须与这些脚本放在同一目录。图 17.4、17.6 的平面零迹线脚本目前自行定义样式，不加载该文件。

使用本机 Mathematica 执行程序。建议在脚本所在目录先保存一个工作笔记本，再在输入单元中载入所需脚本，例如：

```wolfram
Get[FileNameJoin[{NotebookDirectory[], "图10.1-xi实虚曲面联排.wl"}]]
```

此示例要求工作笔记本、绘图脚本和共用样式文件在同一目录。每次选择一个绘图脚本完整执行；多个脚本会清理全局定义，不宜依赖前一脚本留下的变量。三维图可以在 Mathematica 中拖动旋转；部分脚本末尾还显示动态视点坐标，便于选定视角后写回参数并重新导出。拖动屏幕图形不会自动更新已经导出的 PDF。

脚本默认使用 `Songti SC` 中文字体。其他系统若未安装该字体，须将共用样式或脚本自身的 `cjk` 设置改为本机已有的中文字体。

## 参数与导出文件

- 绘图范围主要由 `reMin/reMax`、`imMin/imMax` 或 `sMin/sMax`、`tMin/tMax` 控制；采样与细化主要由 `PlotPoints`、`MaxRecursion` 控制。
- 高度裁切、非线性压缩或归一化属于显示选择，解读前须查看对应脚本和书中图注，不能把显示高度一概当作原函数值。图 13.3 还须保留本书的分支约定，不能直接用默认 `LogIntegral` 替换。
- 多数脚本调用 `bookExport`，将 PDF 写入共用样式所在目录，导出设置为 `ImageResolution -> 600`；该设置不表示三维图中的所有元素都以纯矢量形式输出，也不会自动增加曲面采样精度。
- 图 17.4、17.6 直接使用 `Export` 和 `NotebookDirectory[]`，PDF 写入当前工作笔记本所在目录，因而应先保存笔记本。
- 图 10.1 的脚本一次导出 `图10.1-xi实部曲面.pdf` 和 `图10.2-xi虚部曲面.pdf`；其余绘图脚本各导出相应的单幅 PDF。
- 这些导出不会自动替换书稿的“全书图形”目录。重新生成后，仍须按书稿实际引用的文件名导入，并重新编译检查。重复执行可能覆盖同目录中的同名 PDF。
- `.nb` 是生成时的观察副本，不会随 `.wl` 的修改自动更新。发布新图形时，应同步更新相应笔记本中的已求值输出，不能仅保存尚未运行的代码；免费 Player 读者需要这些已保存的图形。

图形是有限范围内的数值示意；与书中定义、证明不一致时，以正文为准。
