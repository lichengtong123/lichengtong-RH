图中节点表示函数或结论，连线表示它们之间的数学关系；线型只标示连线本身所代表关系的证明状态，虚框表示未证命题（黎曼猜想）。图例与各条连线对应的证明或引用出处见书中第 16 章及其“证明状态索引”。

打印时请选择 A3 纸、不缩放。SVG 文件可用浏览器直接打开，或导入 Inkscape、PowerPoint、Keynote 等软件。
