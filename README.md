### 运行

先按 [运行环境建立与程序安装说明](docs/运行环境建立与程序安装说明.md) 安装所需依赖，并激活已安装 Manim Community 的 Python 环境。在仓库根目录执行：

```bash
cd manim
RH_RENDER_MODE=video python -m manim "二维 ζ 同伦.py" ZetaConformalMap
RH_RENDER_MODE=video python -m manim "Hardy 轨迹.py" zeta_3D_18H
RH_RENDER_MODE=video python -m manim "素数计数公式逼近.py" RiemannVisualization1800log2
```

以上三个命令输出白底、深色线条、1920×1080、30 fps 的完整视频，文件位置见上表；不会覆盖目录中手动保存的旧视频。文件名含空格或中文时须加引号。三个程序共用同目录的 `ch20_render.py`，下载或移动时须一并保留；正式渲染不要设置 `RH_PREVIEW=1`，也不要添加 `-ql` 等低清选项。

作者当前 macOS 环境可先执行以下命令，再运行上述三条渲染命令；其他机器应使用各自的环境名与仓库路径：

```bash
conda activate manim-3b1b
export PATH=/Library/TeX/texbin:$PATH
cd "/Users/lichengtong/lichengtong-RH/manim"
```

白底高分辨率书稿静帧的独立输出方式见 [第20章动画与静帧说明](manim/第20章动画与静帧说明.md)。视频模式与静帧模式分别输出，修改程序后应同步重新生成。

### 修改参数，生成不同的动画

各程序的主要参数集中在文件开头，改后重新运行即可：

| 程序 | 参数 | 含义 |
|------|------|------|
| `二维 ζ 同伦.py` | `x_range_min/max`、`y_range_min/max` | 绘图坐标范围 |
| | `fine_step` | s 平面细网格的间距 |
| | `points_per_line` | 每条网格线的采样点数（越大越光滑、越慢） |
| `Hardy 轨迹.py` | `T_MAX` | 沿临界线的高度上限 t |
| | `DT` | t 的采样步长（越小越密、预计算越久） |
| | `AMPLIFY_FACTOR` | 横截面振幅的显示放大倍数；零点按 `T_MAX` 自动选取 |
| `素数计数公式逼近.py` | `PARAMS["MAXDISTANCE"]` | x 的范围上限 |
| | `PARAMS["NONTRIVIAL_MIN"]`、`["NONTRIVIAL_MAX"]` | 计入的非平凡零点序号范围（截断数 K） |
| | `PARAMS["TRIVIAL_ZEROS"]` | 计入的平凡零点个数 |
| | `PARAMS["DATA_POINTS"]`、`["DRAW_INTERVAL"]` | 采样点数与逐帧绘制间隔 |

例如将 `NONTRIVIAL_MAX` 的默认值 500 改为 10、100，可比较不同零点截断数下的逼近。该参数计正虚部零点数，即纳入的共轭对数；素数跳跃点的完整反演值采用 π₀ 的左右平均约定。

### 使用免费的 Wolfram Player 观察

下载相应 `.nb` 文件后，用 Wolfram Player 打开，直接查看“已求值图形”部分；同一文件中的源码组默认折叠，观察图形不需要执行它，也不需要安装配套 `.wl` 文件。修改后的图形需要由 Mathematica 重新求值并保存输出，Player 不会自动运行外部源码或重新计算整幅曲面。

这里承诺的是查看已保存的图形，不将普通 `.nb` 等同于可运行任意动态控件的应用。旋转、缩放及动态控件的可用范围，应以实际 Player 版本与许可为准；涉及内核求值的交互不能仅凭文件扩展名保证可用。官方对普通 `.nb` 与可交互部署格式的区别见 [Wolfram Player FAQ](https://www.wolfram.com/player-pro/faq/)。

### 在 Mathematica 中修改参数与重新计算

[书图样式.wl](mathematica/书图样式.wl) 不单独生成插图，负责共用视点、字号、中文字体、颜色、线宽、图例、零点标记及 PDF 导出函数；[同名 .nb](mathematica/书图样式.nb) 仅保存样式源码供查阅，不含独立图形。多数绘图脚本通过 `Get` 载入它，须与这些脚本放在同一目录。图 17.4、17.6 的平面零迹线脚本目前自行定义样式，不加载该文件。

使用本机 Mathematica 执行程序。建议在脚本所在目录先保存一个工作笔记本，再在输入单元中载入所需脚本，例如：

```wolfram
Get[FileNameJoin[{NotebookDirectory[], "图10.1-xi实虚曲面联排.wl"}]]
```

此示例要求工作笔记本、绘图脚本和共用样式文件在同一目录。每次选择一个绘图脚本完整执行；多个脚本会清理全局定义，不宜依赖前一脚本留下的变量。三维图可以在 Mathematica 中拖动旋转；部分脚本末尾还显示动态视点坐标，便于选定视角后写回参数并重新导出。拖动屏幕图形不会自动更新已经导出的 PDF。

脚本默认使用 `Songti SC` 中文字体。其他系统若未安装该字体，须将共用样式或脚本自身的 `cjk` 设置改为本机已有的中文字体。

### 参数与导出文件

- 绘图范围主要由 `reMin/reMax`、`imMin/imMax` 或 `sMin/sMax`、`tMin/tMax` 控制；采样与细化主要由 `PlotPoints`、`MaxRecursion` 控制。
- 高度裁切、非线性压缩或归一化属于显示选择，解读前须查看对应脚本和书中图注，不能把显示高度一概当作原函数值。图 13.3 还须保留本书的分支约定，不能直接用默认 `LogIntegral` 替换。
- 多数脚本调用 `bookExport`，将 PDF 写入共用样式所在目录，导出设置为 `ImageResolution -> 600`；该设置不表示三维图中的所有元素都以纯矢量形式输出，也不会自动增加曲面采样精度。
- 图 17.4、17.6 直接使用 `Export` 和 `NotebookDirectory[]`，PDF 写入当前工作笔记本所在目录，因而应先保存笔记本。
- 图 10.1 的脚本一次导出 `图10.1-xi实部曲面.pdf` 和 `图10.2-xi虚部曲面.pdf`；其余绘图脚本各导出相应的单幅 PDF。
- 这些导出不会自动替换书稿的“全书图形”目录。重新生成后，仍须按书稿实际引用的文件名导入，并重新编译检查。重复执行可能覆盖同目录中的同名 PDF。
- `.nb` 是生成时的观察副本，不会随 `.wl` 的修改自动更新。发布新图形时，应同步更新相应笔记本中的已求值输出，不能仅保存尚未运行的代码；免费 Player 读者需要这些已保存的图形。

4. 数值题附算法、参数、精度及可复现代码，区分理论误差界、实测误差与认证结果；图形题附数学解释，不仅给出图片。
