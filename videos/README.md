# 动画视频

本目录仅存放第 20 章的三个新版动画视频（`.mp4`），均为 1920×1080、30 帧/秒。可下载后用系统播放器打开；浏览器是否直接预览取决于其支持情况。生成这些视频的程序见 [manim/](../manim/README.md)。

## 书中引用的视频

| 书中内容 | 视频文件 | 时长 |
|----------|----------|------|
| 二维 ζ 同伦（ζ 映射） | [ZetaConformalMap.mp4](ZetaConformalMap.mp4) | 24 秒 |
| Hardy 轨迹 | [zeta_3D_18H.mp4](zeta_3D_18H.mp4) | 38 秒 |
| π₀ 逼近 | [RiemannVisualization1800log2.mp4](RiemannVisualization1800log2.mp4) | 64.6 秒 |

旧版视频与仓库根目录的旧 HTML 播放页已移除，请使用以上文件。

视频是有限范围内的数值示意；与书中定义、证明不一致时，以正文为准。
