# 检测说明

本页说明送检与统计的做法，供读者与出版方复核。

## 送检文本

送检对象为书稿正文的纯文本，由 `.tex` 源文件剥除 LaTeX 命令、公式环境、图表与脚注后导出。
朱雀的文本检测支持 `txt`、`docx`，不收 PDF，故统一使用 UTF-8 的 txt。

文件名形如 `chapter14-C-02.txt`：

| 段 | 含义 |
|---|---|
| `chapter14` | 章号 |
| `-C` | 送检版本。书稿有 B、C 两版，C 版为按 2026-11-06 修订意见定稿、参加编译的版本 |
| `-02` | 切块序号。整章文本超过 5,500 字符时按段落边界切块，`-01` 为第 1 块；无此段即整章一次提交 |
| `.txt` | 纯文本 |

## 统计口径

| 项 | 规则 |
|---|---|
| 提交单元 | 整章；超过 5,500 字符按段落边界切块 |
| 单次下限 | 350 字（朱雀要求） |
| 三档定义 | 人工特征 < 0.5、疑似 AI 0.5–0.99、AI 特征 ≥ 0.99 |
| 合并方式 | 按各块字符数加权 |
| 覆盖率 | 提交字符数 / 该章正文总字符数；低于 95% 标为「部分」，不计入统计 |
| 未计入 | 公式、图表标题、参考文献表 |

## 如何读这张表

检测反映的是文本形态，不是写作工序。经校对、润色、局部改写后的文字，通常落在人工判定一侧；
反之，体例性、条目化的文字即使完全由人撰写，也可能被判为疑似。
因此本表既不证明未使用 AI，也不证明存在代写。

各环节留下的文本痕迹并不相同：

| 环节 | 文本痕迹 |
|---|---|
| 生成整段初稿并直接采用 | 强 |
| 整段重写、作者基本不改 | 中—强 |
| 翻译外文段落 | 弱—中 |
| 改写个别句子 | 弱，再润色即消失 |
| 查资料、核对定义 | 无 |
| 提出修改建议、作者据此重写 | 无 |
| 校对错别字、标点与格式 | 无 |

## 核验图

每章附一份核验图，取自朱雀报告单「片段解析」以上的部分，包含报告编号、检测时间、
文件名、三档占比与片段明细。图像已栅格化，不含文本层，也不含书稿正文。
自检方法：`pdftotext 文件 - | wc -c`，输出接近于 0。
