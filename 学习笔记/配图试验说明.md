# 三篇学习笔记的配图试验

修订日期：2026-10-23。配图延续书稿图文配合的写法，优先解释坐标、权重与误差之间的关系，不代替正文证明；其余七篇未套用新的版式。

## 图形任务

| 笔记 | 图形 | 对应的数学关系 |
|------|------|----------------|
| Mellin变换与对数坐标 | 正实轴与对数坐标的对应 | 等比取点变为等距取点；乘2变为加log 2；测度dx/x变为du |
| 从矩形求和到平滑求和 | 截断权重与积分核 | 阶跃与连续权重；固定Re s=1时核的尾部衰减 |
| 从矩形求和到平滑求和 | 阶梯函数与一次积分 | a_n=1时A为floor函数，C_1为连续折线；面积8对应C_1(4.5)=8 |
| 渐近级数为什么越加越不准确 | 误差上界与实际误差 | 固定t=0.095，比较N=1至25；最小上界与最小实际误差可以不在同一项数 |

图形均用TikZ或PGFPlots直接生成，采用白底、实线与虚线、明确标记。蓝色不是唯一的区分手段，黑白打印仍可依据线型与点形识别。图中文字、公式与线条保留在PDF中，不使用低分辨率截图。

对数坐标图两行分别采用自己的线性刻度，虚线只连接对应值。平滑图的普通截断在跳点处标出对称反演半权，不混同于右连续计数函数的取值。阶梯函数的实心点、空心点分别表示右连续值与左极限。

渐近截断图对应笔记中的F(t)，不是Li的数值误差图。横轴N表示保留从k=0到N-1的N项，b_N=N!t^N则是下一项绝对值与已证余项上界。最小值比较限定为图示范围内的数值结果，不将最小项截断当作无条件的普遍定理。

## 源码与编译

三篇各自的 `figures/` 目录保存绘图源码。下载LaTeX源码时须保留该目录，以及上一级共用的 `notes-common.tex`。进入相应笔记目录后，用XeLaTeX连续编译两次与目录同名的主文件即可。

第5篇另附 `generate_figure_data.py`、`figures/truncation-data.csv` 和 `figures/truncation-summary.tex`。现成数据随仓库发布，直接编译不需要Python。

要复算第5篇数据，在该篇目录执行：

```bash
python3 -m pip install mpmath
python3 generate_figure_data.py
xelatex -interaction=nonstopmode -halt-on-error 05-渐近级数为什么越加越不准确.tex
xelatex -interaction=nonstopmode -halt-on-error 05-渐近级数为什么越加越不准确.tex
```

程序固定t=0.095、N=1至25，以80位工作精度计算，并以120位精度复算；实际误差同时由精确余积分与部分和之差计算，核对两者和已证严格上界。复算的数值一致性不是区间认证。程序会更新本篇的CSV与数值宏，不改动其他笔记。

同步修正两处直接相关的表述：第1篇将Laplace代换变量改为v，避免与对数坐标u的方向冲突；第2篇将分母的增长表述改为“与相应幂次同阶”，使积分核衰减的理由充分。原有证明与适用条件保留。
