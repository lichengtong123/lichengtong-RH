# AIGC 检测结果

本书在成稿与修订过程中使用了生成式 AI 工具（Anthropic 的 Claude、OpenAI 的 GPT 系列模型、深度求索公司的 DeepSeek 等），用途包括：

- 资料检索，文献与引文核对；
- 数学推导与数值的核验，查找推导中的缺口并提出修改建议；
- 外文翻译：英文审阅版主要由 AI 翻译，并随中文修订同步；
- 文字校对、语句润色与排版修订。

AI 提出的修改建议均由作者逐条核实后取舍；数学内容与全部结论由作者核定，文责由作者承担。
AIGC 检测只反映送检文本的语言特征，不能说明写作与修订中是否使用了 AI；AI 的使用情况以本说明为准。

2026 年 11 月，全书 25 章逐章送检（朱雀 AI 检测助手，模型版本 2026-07-21）。
分章结果见 [分章结果.md](结果/分章结果.md)，原始报告单见 [核验图/索引.md](核验图/索引.md)。
