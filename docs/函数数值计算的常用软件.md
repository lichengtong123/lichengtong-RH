

# ζ 函数数值计算的常用软件

本页介绍计算 ζ 函数值、非平凡零点、素数计数函数时常用的软件与数据，对应书中第 19 章（非平凡零点的数值计算与显式公式逼近）。各软件的安装与完整用法以其官方文档为准。

## 一、通用数学软件

| 软件 | 类型 | 与本书相关的主要函数 | 说明 |
|------|------|----------------------|------|
| **mpmath**（Python） | 开源，任意精度 | `zeta`、`zetazero(n)`、`siegelz`（Hardy Z）、`siegeltheta`（Riemann–Siegel 相位 ϑ）、`grampoint(n)`、`nzeros(T)`、`li`、`riemannr`、`primepi` | 本仓库 Manim 程序所用；上手最快，适合做书中各章的数值核对 |
| **Wolfram Mathematica** | 商业 | `Zeta`、`ZetaZero[n]`、`RiemannSiegelZ`、`RiemannSiegelTheta`、`PrimePi`、`LogIntegral`、`RiemannR` | 本书曲面图、零迹线图所用；三维图可交互旋转 |
| **PARI/GP** | 开源，数论专用 | `zeta`、`lfun`、`lfunzeros`、`primepi` | 速度快；`lfun` 系列也可算 Dirichlet L 函数（书中第 22 章 §22.5） |
| **SageMath** | 开源，集成环境 | `zeta`、`prime_pi`、`lcalc` 接口 | 内含 PARI 与 Rubinstein 的 lcalc，可在一个环境中调用 |

## 二、专用与严格计算

| 软件 | 说明 |
|------|------|
| **FLINT（原 Arb）** | 球算术（区间算术），每个结果都附带严格误差界。含 ζ 零点的严格计算（如 `acb_dirichlet_zeta_zeros`、`acb_dirichlet_hardy_z`），是「有限高度内 RH 成立」这类严格验证所用的工具；Python 可通过 `python-flint` 调用 |
| **lcalc**（M. Rubinstein） | C++ 程序，计算 ζ 与各类 L 函数的值和零点；SageMath 已集成 |
| **primecount**（K. Walisch） | 用组合算法计算极大 x 的 π(x)（可到 10²⁵ 量级以上），可与 li(x)、R(x) 对照 |

## 三、零点数据

| 数据 | 说明 |
|------|------|
| **A. Odlyzko 零点表** | 前 100 000 个零点（精度约 3×10⁻⁹），以及 10²⁰、10²¹、10²² 附近的零点；书中第 18 章引用。https://www.dtc.umn.edu/~odlyzko/zeta_tables/ |
| **LMFDB** | L 函数与模形式数据库，收录 D. Platt 严格计算的大量 ζ 零点，可在线查询。https://www.lmfdb.org |

## 四、最小示例（mpmath）

```python
from mpmath import mp, zeta, zetazero, nzeros, siegelz, grampoint, li, riemannr, primepi
mp.dps = 20                      # 十进制有效位数

rho1 = zetazero(1)               # 第一个非平凡零点 1/2 + 14.134725...i
print(rho1, abs(zeta(rho1)))     # |ζ(ρ₁)| 应接近 0

print(nzeros(100), nzeros(1000)) # N(100) = 29，N(1000) = 649
print(siegelz(20.0))             # Hardy Z(t)，实值
print(grampoint(126))            # 第 126 个 Gram 点 ≈ 282.4547

x = 10**6
print(primepi(x), li(x), riemannr(x))   # 78498，≈78627.5，≈78527.4
```

## 注意

1. 浮点计算（mpmath、Mathematica 默认精度、PARI）给出的是数值近似，不是严格证明；严格验证须用区间算术（如 FLINT）并配合 Turing 方法，见书中第 19 章。
2. `zetazero(n)` 对较大的 n 较慢；需要大量零点时，直接读取 Odlyzko 表或 LMFDB 数据更快。
