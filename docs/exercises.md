# 练习

下列练习配合书中各章，供读者自行检验。本页是数值练习，用 mpmath（见 [numerics.md](numerics.md)）或 Mathematica 即可完成，均给出参考结果；推导练习另见 [exercises-mainline.md](exercises-mainline.md)。练习不属于书中正文，也不影响正文的逻辑。

## 一、数值练习

**练习 1（第 9、11 章：零点与对称性）**
计算前 10 个非平凡零点 ρₙ = 1/2 + iγₙ，验证 |ζ(ρₙ)| 在计算精度内为 0；再验证 ζ(ρ̄ₙ)、ζ(1−ρₙ) 也为 0。
*参考：* γ₁ = 14.134725…，γ₁₀ = 49.773832…

**练习 2（第 9 章：特殊值与函数方程）**
验证 ζ(0) = −1/2、ζ(−1) = −1/12、ζ(2) = π²/6；任取 s = 0.3 + 5i，数值验证函数方程 ζ(s) = 2ˢπˢ⁻¹ sin(πs/2) Γ(1−s) ζ(1−s)。

**练习 3（第 11 章：Riemann–von Mangoldt 公式）**
用 `nzeros(T)` 计算 N(T)，与主项 (T/2π) log(T/2πe) + 7/8 比较，取 T = 100、1000、10000。观察二者之差 S(T) 的大小。
*参考：* N(100) = 29；N(1000) = 649，主项 ≈ 648.6。

**练习 4（第 19 章：Hardy Z 函数）**
在 [0, 50] 上以步长 0.01 计算 Z(t)，数出变号次数，与 N(50) 比较。
*参考：* 10 次，对应 γ₁, …, γ₁₀（γ₁₀ ≈ 49.77 < 50 < γ₁₁ ≈ 52.97）。

**练习 5（第 19 章：Gram 定律）**
对 n = 0, 1, …, 200 计算 Gram 点 gₙ 与 (−1)ⁿZ(gₙ)。Gram 定律断言它为正；找出它首次不成立的 n。
*参考：* 首次失效在 n = 126（g₁₂₆ ≈ 282.455），其后 n = 134、195 也失效。这说明 Gram 定律只是经验规律，需要 Turing 方法补足。

**练习 6（第 14 章：显式公式的截断）**
取 x = 100.5，用截断显式公式
ψ₀(x) ≈ x − Σ_{n≤K} 2 Re(x^{ρₙ}/ρₙ) − log 2π − ½ log(1 − x⁻²)
计算 K = 10、50、100 的值，与 ψ(100.5) 比较。
*参考：* ψ(100.5) = 94.0453…；K = 10、50、100 时依次约为 95.78、94.91、95.01。收敛是条件收敛且很慢，这正是书中区分截断误差与主项误差的原因。

**练习 7（第 1、13 章：π(x) 与 li(x)、R(x)）**
对 x = 10³、10⁴、10⁵、10⁶，计算 π(x)、li(x)、Riemann 函数 R(x)，比较 li(x) − π(x) 与 R(x) − π(x) 的大小。
*参考：* x = 10⁶ 时 π = 78498，li ≈ 78627.5，R ≈ 78527.4。

**练习 8（第 20 章：动画参数）**
在 `manim/素数计数公式π0(x)逼近.py` 中把 `PARAMS["NONTRIVIAL_MAX"]` 依次改为 10、100、1000，重新渲染，观察逼近曲线在素数处的跳跃如何随 K 增大而变陡。
