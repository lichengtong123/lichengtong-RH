# Lean 入门示例

本目录面向初次接触形式化证明的读者，通过由易到难的数学例子，介绍 Lean 的基本使用方法、操作步骤、证明写法及核验结果的理解。选题取自本书涉及的数学内容，但不按章节排列，也不编排为系统的 Lean 课程。每段证明配有中文注释，说明输入条件、中间结论和实际使用的推理。

建议先阅读 3–4–1 三角不等式及配套操作说明，再按需要阅读涉及有限求和、反演和分析方法的例程。各项均可按兴趣与需要选读，两个补充例程不构成必读前提。

可以调用已经核验的基础理论与一般引理，但不以直接引用现成目标定理代替本例要展示的证明。各例程的完成范围不同，以下分别说明。

## 3–4–1 三角不等式

代码先用余弦倍角公式和多项式恒等变形证明

$$
3+4\cos\theta+\cos(2\theta)=2(1+\cos\theta)^2,
$$

再由实数平方非负及非负数乘积非负推出不等式。`ring` 只处理其中的代数整理，不替代倍角公式与非负性推理。

配套[逐步说明 PDF](ThreeFourOne-逐步说明.pdf)解释每条指令、证明状态的变化，以及 VS Code 中的操作和 InfoView 显示，截图已包含在文档中。读者可直接阅读，无须配置 LaTeX 环境；说明的排版源码只在作者本机维护。

本书第 9.6.2 节及附录 F.1 使用这一非负三角式；本例不包括后续关于 ζ 的级数、无零点论证或零点自由区估计。

## von Mangoldt 恒等式与 Möbius 反演

对正整数 n，先通过素数幂与互素乘积归纳证明

$$
\sum_{d\mid n}\Lambda(d)=\log n,
$$

再将它写成 Dirichlet 卷积，利用一般 Möbius 逆关系逐步推出

$$
\Lambda(n)=\sum_{d\mid n}\mu(d)\log(n/d).
$$

代码没有直接调用这两个现成目标公式。基础输入包括素因子分解归纳、因子枚举、对数乘法公式与一般卷积理论；证明中逐项解释它们的作用。

代码使用满足 de=n 的有序因子对展开反演有限和。算术函数的记号 ζ 表示正整数上恒为 1 的函数，不是复变函数 ζ；卷积单位元也不是普通的常值函数 1。库在 n=0 处的补值约定使代码还覆盖该点，但通常的数论公式仍取 n≥1。

因子和证明改编自 Bhavik Mehta 编写的 mathlib `VonMangoldt.lean`，保留来源说明，按 [Apache-2.0](Apache-2.0.txt) 发布。其余文件的许可见[上级说明](../README.md#许可)。

## 函数方程：当前仅完成代数片段

`ThetaFramework.lean` 对任意复函数 A 定义模型

$$
F_A(s)=-\frac1s-\frac1{1-s}+A(s)+A(1-s),
$$

并实际证明代数对称性 F_A(1-s)=F_A(s)。这里的 A 尚不是已经识别的含参量积分，也未证明 F_A 等于完备化 ζ 函数。因此，文件通过 Lean 核验不表示 ζ 函数方程已经形式化。

完整推导还需逐项完成以下接口：

- 将已核验的 Jacobi ϑ 模反演专门化到本书采用的实参数级数，并核对定义与分支。
- 从 Γ 的积分及 ζ 的绝对收敛级数建立 Mellin 表示，证明求和换序所需的绝对可积性。
- 在 1 处分拆积分，用模反演和变量代换处理小区间，并计算有理函数修正项。
- 利用指数衰减给出参数紧集上的共同可积控制，证明积分项的解析性。
- 在共同区域识别新表示与库中 ζ、Γ 的定义，再由延拓唯一性得到函数方程；不能只构造一个对称函数便结束证明。

上述分析接口尚未完成。实现时允许调用一般积分、极限及解析函数理论，不直接引用现成的 ζ 函数方程，也不把缺失接口作为未经证明的额外公理。

## 自选补充

`ShiftStableSum.lean` 对应学习笔记第 11 篇。它用常数序列说明：如果对每个实数序列都赋予有限实数值，并且一律要求“总和等于首项加尾序列的和”，就会得到 S=1+S 的矛盾。这不否定通常收敛级数的求和，也不把正则化赋值当作通常意义下的级数和。

`Mersenne61.lean` 对应学习笔记第 16 篇。它不重新证明一般 Lucas–Lehmer 判据，而是把特定整数的值、递推测试证书和判据的应用分别展开。读者可借此观察有限计算如何成为可核验的证明输入，不必将它与前面的三角恒等式视为同一种难度。

两个补充例程均按题目命名，不另标难度等级；初次阅读仍可从 `ThreeFourOne.lean` 及其逐步说明开始。

## 运行方法

在项目根目录 `形式化证明-使用Lean4核验本书数学推导/` 中执行，而不是在本子目录中直接启动：

```sh
lake build
```

单独检查 3–4–1 例程：

```sh
lake env lean Lean入门示例/ThreeFourOne.lean
```

只构建本组模块：

```sh
lake build Lean入门示例
```

需要逐步观察时，在 VS Code 中打开项目根目录，再打开对应 `.lean` 文件并将光标移到证明指令处。详细操作与“证明通过”的判断范围见上述配套 PDF。
