# 动画视频

本目录存放第 20 章动画的成片（`.mp4`），可下载后用系统播放器打开，也可通过仓库根目录的网页在浏览器中播放。生成这些视频的程序见 [manim/](../manim/README.md)。

## 书中引用的视频

| 书中内容 | 视频文件 | 浏览器播放页 |
|----------|----------|--------------|
| 二维 ζ 同伦（ζ 映射） | `ZetaConformalMap-100.mp4` | [Conformal-100.html](https://lichengtong123.github.io/lichengtong-RH/Conformal-100.html) |
| Hardy 轨迹 | `Hardy-轨迹.mp4` | [Hardy.html](https://lichengtong123.github.io/lichengtong-RH/Hardy.html) |
| π₀ 逼近 | `素数计数公式π0(x)逼近.mp4` | [J2pi.html](https://lichengtong123.github.io/lichengtong-RH/J2pi.html) |
| 3B1B 式全平面变换（书中未印） | `3B1B.mp4` | [3B1B.html](https://lichengtong123.github.io/lichengtong-RH/3B1B.html) |

本目录其余视频是 ζ 映射在不同零点个数和坐标范围下的早期版本，仅供比较，书中不引用。

视频是有限范围内的数值示意；与书中定义、证明不一致时，以正文为准。
