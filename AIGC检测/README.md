# AIGC 检测结果

本书在成稿与修订过程中使用了生成式 AI 工具（Anthropic 的 Claude、OpenAI 的 GPT 系列模型、深度求索公司的 DeepSeek 等），用途包括：

- 文献与引文核对；
- 证明复审与数值核验：查找推导中的缺口并提出修改建议；
- 部分文字的润色与排版修订；
- 英文审阅版的翻译：译文主要由 AI 生成，并由作者修订，随中文修订同步。

AI 提出的修改建议均由作者逐条核实后取舍；数学内容与全部结论由作者核定，文责由作者承担。与书中前言“AI 工具的使用”一节所述一致；英文审阅版前言另注明其译文的来源。
AIGC 检测只反映送检文本的语言特征，不能说明写作与修订中是否使用了 AI；AI 的使用情况以本说明为准。

全书分别送两家检测：知网 AIGC 检测（全文一次提交）与朱雀 AI 检测助手（逐章提交）。两家的算法与统计口径不同，数值不宜直接比较。
