# 学习笔记

本目录各篇为学习笔记初稿，不是新增研究成果。文中区分直接证明与引用结果；本书正文不依赖这些笔记。

## 从哪里开始

初次阅读，建议从《有了显式公式为什么还需要素数定理》开始，再读《黎曼猜想在素数分布中的确切位置》与《数值证据的逻辑地位》。这三篇先澄清全书主要结论之间的关系，不要求先学习一套新的技术。

下面按理解深化优先、再逐步进入方法与技术延伸的顺序编排。各篇可以按兴趣选择，不必依次通读。文件名前的编号是固定的专题编号，供篇间引用使用，不表示阅读难度或先修次序。
