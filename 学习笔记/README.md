# 学习笔记

围绕素数、ζ 函数及相关数学问题，整理具有参考价值的证明、推导与说明，供有兴趣的读者选择阅读。

**正文自足，延伸自选。** 这些笔记可引用本书已有结论作为前提，但本书的论证不依赖笔记。各篇按问题组织，不按书中章号编排。必要背景可以重述，主体应承担独立任务，而不是复制正文。

笔记是本书内容的边沿补充。选题与形式可以相对自由，鼓励具有数学趣味的问题探究、计算札记、程序实验，以及对黎曼猜想某一角度的思想性讨论；各篇风格可以不同，不要求逐章对应或统一模板。题材可以轻松，叙述仍保持学术规范，数学论述须准确、完整、自洽。历史与人物不单独成篇，可参看卢昌海《黎曼猜想漫谈》。

## 文件与编译

正式阅读内容用 LaTeX 编写，PDF 为对应的阅读版本；本索引不另行维护第二份全文。每篇目录中的 LaTeX 源码与 PDF 均与目录同名（如 `01-Mellin变换与对数坐标/01-Mellin变换与对数坐标.tex`），共用上一级的 notes-common.tex。只下载某篇源码时，也须保留这一共用文件的相对位置。

采用 XeLaTeX，使用 TeX Live 通常附带的 Fandol 中文字体，不依赖作者本机的 macOS 中文字体。在相应专题目录内执行两次：

```bash
cd 01-Mellin变换与对数坐标
xelatex -interaction=nonstopmode -halt-on-error 01-Mellin变换与对数坐标.tex
xelatex -interaction=nonstopmode -halt-on-error 01-Mellin变换与对数坐标.tex
```

其他各篇同样进入相应目录，编译与目录同名的 `.tex` 文件。修改共用样式后须重新编译各篇。PDF 与源码一同发布，避免只更新其中一份。

第 11–21 篇使用 fontspec、xeCJK，并由共用模板统一设置 Fandol 中文字体，无须安装 macOS 的 Songti SC 字体。

第 21 篇的代码使用 TeX Live 附带的 DejaVu 字体。

第 1、2、5、7、10、20 篇使用 TikZ 或 PGFPlots 绘图，下载源码时还须保留该篇的 `figures/` 目录。TeX Live 通常附带相应宏包。第 5 篇已附绘图数据，直接编译不需要 Python；只有重算其数据时才需要 Python 和 `mpmath`。第 7、10 篇的模型可用仅依赖Python标准库的 `核验配图模型.py` 复核，编译不需要运行该脚本。

第 16 篇附有 `认证示例.py`，使用 `python-flint` 0.9.0 在160、224位二进制精度下核查文中的十进制上下界。第 17 篇附有 `计算比较数据.py`，依赖 `mpmath`、`numpy`、`sympy`；运行 `python3 计算比较数据.py --dps 30 --check` 可复算表格，改用 `--dps 50` 可提高工作精度。缓存写入系统临时目录，不在阅读目录内产生数据文件。后者是普通数值实验，不是区间认证；自由系数的最小二乘输出仅作数值诊断。
