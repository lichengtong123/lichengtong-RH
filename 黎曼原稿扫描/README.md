# Riemann 1859 年原稿扫描

本目录收录 B. Riemann 论文 *Ueber die Anzahl der Primzahlen unter einer gegebenen Grösse*（《论小于给定数值的素数个数》）的德文原文扫描本，供对照书中第 21 章「Riemann 原稿解读」的中文译稿阅读。

| 项目 | 说明 |
|------|------|
| 文件 | [Ueber_die_Anzahl_der_Primzahlen_unter_einer_gegebenen_Grösse.pdf](Ueber_die_Anzahl_der_Primzahlen_unter_einer_gegebenen_Grösse.pdf)（9 页，约 2.2 MB） |
| 首次发表 | *Monatsberichte der Berliner Akademie*, November 1859 |
| 扫描所据版本 | B. Riemann, *Gesammelte mathematische Werke und wissenschaftlicher Nachlass*, herausgegeben von H. Weber unter Mitwirkung von R. Dedekind, Leipzig: B. G. Teubner, 1876, S. 136–144（文集第 VII 篇） |
| 扫描来源 | [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Ueber_die_Anzahl_der_Primzahlen_unter_einer_gegebenen_Gr%C3%B6sse.pdf) |
| 版权状态 | 公有领域（作者卒于 1866 年，著作权保护期已届满） |

书中第 21 章的译稿以这一版本为底本，按原文次序翻译，并在相应段落之后附编者解读。扫描本中的原稿记号与本书记号的对应关系，见第 21 章开头的记号对照表。
