# 动画视频

本目录存放第 20 章的三个新版动画视频（`.mp4`）及播放页，视频均为 1920×1080、30 帧/秒。可在浏览器播放，也可下载后用系统播放器打开。生成这些视频的程序见 [manim/](../manim/README.md)。
