# 书稿评价（非正式审稿）

以下针对现行书稿《素数分布与黎曼猜想》，供配套页读者参考。  
**不是**期刊同行评议，也不代表已出版定稿。

---

《素数分布与黎曼猜想》是一部以 Riemann \(\zeta\) 函数及其零点理论为核心、以「理解黎曼猜想知识谱系的最小必要数学基础」为明确目标的解析数论专题著作。全书从素数计数函数出发，经 Möbius 与 von Mangoldt 算术函数、Dirichlet 级数、Euler 乘积、Gamma 函数、解析延拓与函数方程，逐步建立 \(\xi\) 函数、Hadamard 乘积、非平凡零点、零点计数函数及 Riemann 显式公式，并将零点项改写为对数余弦逼近，最终把黎曼猜想置于素数分布误差项的层级结构中。

本书较为突出的特色，是在传统解析数论知识链之外建立了贯穿全书的几何解释路线，并将 \(\zeta\)、\(\xi\) 的实部、虚部、模以及零迹线与非平凡零点、临界线和显式公式联系起来（图形示意不代替证明）；同时通过 Hardy \(Z\) 函数、Riemann–Siegel 公式和有限零点截断重构，将理论对象与数值计算相连接，并以 Riemann 1859 年原稿和当代研究前沿作为历史与现代延伸。

从数学写作的规范性看，本书目前已经较好地区分了定义、定理、证明、证明提要、数值实验和几何示意的逻辑地位，尤其明确区分素数定理、显式公式和黎曼猜想三个不同层级，这是本书学术结构上的重要优点。

本书并不试图覆盖现代解析数论的全部问题，而是有意识地排除孪生素数、有界间隙、Goldbach 等与本书知识主线无直接必要联系的问题。这种范围控制与「最小必要数学基础」的目标一致，并不构成学术缺陷。

在正式出版前，建议重点完成数学事实的最后核查，尤其是 Mertens 等价的陈述级表述与文献出处、数值计算误差的表述、共形映射与同伦变形术语、零点密度及当代前沿文献的原始出处，以及全文符号和证明责任的最终统一。完成这些终校后，本书有望形成一部具有较强系统性、可核对性和几何解释特色的黎曼猜想专题专著。
