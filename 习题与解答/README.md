# 习题与解答

本栏目为希望通过独立思考、推导和计算深化理解的读者提供自选练习，与“学习笔记”并列。学习笔记直接展开专题论述，本栏目则以题目为起点，逐步配备提示与参考解答；本书正文的论证不依赖这些练习。

## 当前材料

**预选习题草稿，现附提示，参考解答陆续补充。**

- [数学推导练习（第 2–15 章）](<数学推导练习（第 2–15 章）.md>)：沿用原有预选题，含补全、重做、变式和理解等类型，附提示或部分参考结果。

这些题目尚未形成审定习题集，完整参考答案尚未齐备。题目可解性、提示的充分性、前提条件及书内编号仍须逐项复核；文件迁入本栏目不表示已经完成数学审定。当前迁移保留原文，不改变题意或答案。

## 计划补充的题型

纸质书保留完整的数学论证，不设习题章节；本栏目为有练习需求的读者提供自选材料，题目的数量、难度和解释方式根据读者反馈调整。计划中的题型如下，尚未逐一编选：

| 类型 | 目的 | 适合的题目示例 |
|------|------|----------------|
| 定义与概念辨析 | 准确理解对象及结论 | 第 2 章比较 Λ(12) 与对 12 的全部因子求 Λ 的和；第 8 章区分函数与级数表示的定义域 |
| 基本计算与公式应用 | 将定义落实到具体对象 | 手算若干处 J、θ、ψ 的值及左右平均值，用 Möbius 反演恢复 π |
| 主线推导复现 | 独立掌握关键方法 | 由 Euler 乘积推出对数导数级数；由 Perron 核解释跳跃点的半权；复现显式公式的四类留数 |
| 条件检查与错误诊断 | 理解每项假设的作用 | 检查换序和移线的依据；辨认条件收敛级数的错误重排；说明零点对称性为何不足以推出 RH |
| 图形与动画解释 | 将数学表达式与可视化联系 | 区分实部零迹线与函数零点；解释 Hardy 相位归一化；说明动态截图为何不等于某时刻的函数零点图 |
| 数值实验与结果复核 | 将熟悉的计算方法用于本书对象 | 重算书中初等函数表；改变零点截断数比较误差；区分近似零点、严格定位和完整计数 |
| 跨章综合 | 把握整条推理链 | 从 Λ 的级数走到 ψ 的积分表示与显式公式；解释素数定理、精确表示与 RH 误差界的不同任务 |
| 进一步讨论与文献阅读 | 为有需要的读者准备研究入口 | 比较平滑前后的零点和收敛性；核对一项前沿定理的假设、结论及与 RH 的逻辑关系 |

初期每章先选 3–5 道有代表性的题。第 16、20、21、22 章可侧重关系辨析、图像解释、原稿对照和文献阅读，不必配成证明题。

## 后续编排

- 题目、提示与完整参考解答分开呈现，便于读者先独立思考。
- 参考解答应写明条件和关键步骤；数值题还须说明算法、精度与结果的认证范围。
- 选题以理解深化为主，保留适量延伸，不以课堂教学或统一完成进度为要求。
- 根据读者反馈调整题目、提示和解答，成熟后逐题注明复核状态与修订日期。

反馈请在仓库 Issues 中注明题号、题目名称及具体疑问。讨论题的参考分析不要求唯一措辞，未完成复核的提示也不应当作已经认证的标准答案。
